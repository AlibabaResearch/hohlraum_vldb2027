# Hohlraum

Repository layout:

- `hohlraum/preprocessing/`: dataset preprocessing.
- `hohlraum/hisim/`: HiSim integration.
- `hohlraum/sglang/`: native SGLang integration.
- `hohlraum/policy_replay/`: policy replay.
- `hohlraum/experiments/`: clients and experiment framework.
- `hohlraum/shared/`: shared algorithms.
- `hohlraum/docs/`: documentation.
- `scripts/`: installation and entry points.
- `third_party/sglang/`: unmodified SGLang source, including HiSim.

This baseline imports upstream commit `e00930c5489053f26d86b179cee0d087f846acbb`.
Subsequent integration changes can be reviewed against this commit.
